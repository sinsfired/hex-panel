Running patterns

None. Pick tiles, choose a pattern and press Apply. Each selection you apply keeps its own pattern.

Right-click a hex (or press Delete on it) to turn just that hex off. Do it again to turn it back on.

WLED setup

In WLED, set the LED count to (LEDs per hex × 47) + offset. Realtime UDP must be on (Config › Sync Interfaces › Receive UDP realtime), which is the default.
